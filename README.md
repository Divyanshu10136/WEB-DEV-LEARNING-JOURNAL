# 🌍 How a Website Loads

Understanding what happens when a user enters a URL is an important part of web development.

A simplified request flow looks like this:

```text
Browser
   ↓
DNS
   ↓
HTTP/HTTPS
   ↓
Server
   ↓
Application
   ↓
Database
   ↓
Response
   ↓
Browser
   ↓
Rendered Website
```

Important concepts include:

* DNS lookup
* TCP connection
* TLS/HTTPS
* HTTP request
* Server processing
* Database queries
* HTTP response
* Browser rendering
